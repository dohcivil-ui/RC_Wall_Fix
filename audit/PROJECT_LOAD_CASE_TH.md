# กรณีแรงของโปรเจกต์: Active และ Passive เต็มค่า

**ใช้แรงดันดินทั้งสองฝั่งร่วมกันในกรณีออกแบบเดียว ตามเงื่อนไขที่ผู้ใช้กำหนด** ด้านหลังระดับ H ให้ active; ด้านหน้าระดับ H1=1.20 ม. ให้ passive เต็มค่า พารามิเตอร์ WSD ใช้ n=Es/Ec หลังผู้ใช้อนุญาตและตรวจผลกระทบแล้ว

การเพิ่มกรณีเปรียบเทียบในรอบก่อนเป็นสิ่งที่ผู้ช่วยเพิ่มเอง ไม่ใช่เงื่อนไขออกแบบที่ผู้ใช้ต้องการ จึงเอาออกจากชุดคำนวณมิติ/เหล็ก/ราคาและรายงานปัจจุบันแล้ว หลักฐานการรันก่อนหน้าคงอยู่ในโฟลเดอร์ประวัติ

## ระดับดินและแขนแรง

H และ H1 วัดจาก **ท้องฐาน** ตามนิยามเดิมของโปรเจกต์:

| การคำนวณ | ความสูง/แขนแรงที่ใช้ |
| --- | --- |
| Active ทั้งกำแพง | Pa=½KaγH², แขน H/3 เหนือท้องฐาน |
| Passive ทั้งกำแพง | Pp=½KpγH1², แขน H1/3 เหนือท้องฐาน |
| Active ต่อ stem เหนือฐาน | hs=H−TBase, แขน hs/3 เหนือผิวฐาน |
| Passive ต่อ stem เหนือฐาน | hp=H1−TBase, แขน hp/3 เหนือผิวฐาน |
| น้ำหนักดินบน heel | γ·LHeel·(H−TBase) ต่อความยาวกำแพงหนึ่งเมตร |

ระดับบนของดินด้าน heel คือ H แต่ความหนาดินที่วาง **เหนือผิวฐาน** คือ H−TBase การหักนี้ไม่นับปริมาตรคอนกรีตฐานซ้ำเป็นน้ำหนักดิน

สำหรับกรณี H=5.00, H1=1.20, TBase=.30 ม., γ=1.8 ตันแรง/ม.³, φ=30°:

- Ka=1/3, Kp=3; Pa=7.5000 และ Pp=3.8880 ตันแรง/ม. ใช้แขน 1.6667 และ .4000 ม. ตามลำดับ
- hs=4.70, hp=.90 ม.; โมเมนต์ active ที่โคน stem=10.3823 และ passive=.6561 จึงได้โมเมนต์สุทธิ **9.7262 ตันแรง·ม./ม.**
- ทั้งสองแรงเข้าสู่ FS พลิกคว่ำ, FS เลื่อน และสมดุลเพื่อหา eccentricity/แรงดันใต้ฐาน จากนั้นแรงดันใต้ฐานเข้าสู่โมเมนต์ toe/heel

## การแก้โค้ด

[modShared.bas](../modShared.bas) กำหนด `PROJECT_PASSIVE_FACTOR=1` และตั้ง `PassiveFactor` ตามค่านี้ใน `InitializeArrays` ซึ่งถูกเรียกตอนโหลดฟอร์มและเริ่มค้นหา BA/HCA จึงให้หน้าจอและการค้นหาจริงใช้เงื่อนไขเดียวกับชุดรายการคำนวณ

ค่าเริ่มต้นในฟอร์มเดิมยังไม่ได้ตั้งให้ตรงกับกรณีหลักใน harness จุดนี้ถูกแก้แล้ว เพิ่ม regression ตรวจทั้งตอนเปิด Form1 และหลังเรียกปุ่ม BA/HCA จริง ไม่เปลี่ยนสูตรราคา สูตรแรง หรือ BA ที่บีบเฉพาะ tb/TBase/Base

`build_full_sizing.py` สร้างกรณีออกแบบเดียวที่ใช้ทั้งสองแรง `verify_full_sizing.py` และ `verify_recalculation_details.py` ตรวจกรณีเดียวกัน พร้อมเก็บ input manifest ที่ระบุ passive_factor=1

## ผลที่ต้องอ่านร่วมกัน

มิติและราคาที่เลือกต้องผ่านเสถียรภาพทั้งสามก่อน แล้วจึงตรวจหน้าตัดและเปรียบเทียบราคา รายละเอียดพารามิเตอร์ n,k,j,R อยู่ใน [รายงาน WSD](MODULAR_RATIO_DECISION_TH.md) การยืนยันรูปแบบแรงนี้ไม่ได้เปลี่ยนสถานะเกณฑ์ WSD ส่วนอื่นที่ยังไม่ครบ
