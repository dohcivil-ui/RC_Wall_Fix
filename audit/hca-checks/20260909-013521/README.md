# HCA search diagnosis and final main-steel sweep

Baseline source: 05df37e. The user's current H5/fc320 sessions are BA-25690909-012919-seed12345 and HCA-25690909-012827-seed12345, each 30 trials of 5000 evaluations, seeds 12345–12374. Existing user output was read only; new runs were isolated below this audit folder.

## Findings

The trace audit checked all 300000 evaluations and final best/evaluation values against both trial summaries. No lost feasible global-best update was found. All inputs match: H5/H1=1.2, fc320/SD40, cover75mm, qa30, full active/passive. BA's minimum was 8540.19588 and HCA's minimum 8573.88408, a difference of 33.68820 Baht/m (about 0.394%). HCA accepts the actual BA best design at 8540.19588 when given the same initial design and a one-evaluation budget.

The original HCA changes all eleven indices together and accepts only cheaper valid candidates. Randomized trials within finite budgets do not guarantee that BA and HCA find equal minima. For the user's HCA winner, native checks found cheaper valid one-member bar changes: toe DB16@0.20 costs 8551.96824 with other variables fixed; heel DB25@0.25 costs 8560.33476. The original heel spacing step is at most two indices, so the move from @0.10 to @0.25 cannot occur directly. Independent changes in other variables also make a narrowly feasible candidate harder to propose. This is a neighborhood limitation, not an error in the common engineering checker or best bookkeeping.

## Final change

`modHillClimbing.bas` retains its original GenerateNeighbor routine and greedy acceptance. For budgets greater than 120, it reserves the final 60 evaluations for a sweep through the existing 5 diameters × 4 spacings for each of stem/toe/heel. Geometry is held fixed during that final sweep; feasible cheaper candidates update current and RunBest through EvaluateCandidate as usual. Every sweep candidate consumes one evaluation. At budget 5000 the first 4940 evaluations are unchanged. Runs of 120 evaluations or fewer retain the old random search throughout.

This is an explicit improvement to HCA's search policy, named HCA_FINAL_MAIN_STEEL_SWEEP_V1 in run.txt. It is not a claim that the original HCA bookkeeping was broken, a guarantee of global optimality, or a guarantee of equality with BA in every trial. Research comparisons must describe this added final HCA neighborhood sweep. BA source and its three-variable contraction remain unchanged. No engineering equations, pass criteria, material prices, CSV columns or evaluation budgets were relaxed.

Only production files modHillClimbing.bas and modShared.bas changed; the latter adds the HCA policy/count to the existing run report. Diagnostic source copies in before/after/final are not active project files.
