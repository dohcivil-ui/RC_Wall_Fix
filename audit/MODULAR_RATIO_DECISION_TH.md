# ผลประเมิน: เลือก n=Es/Ec เพราะมีผลต่อการตัดสินหน้าตัด

**ควรใช้ n=Es/Ec ตามสมการใน ref สำหรับโปรเจกต์นี้** ผลต่างจากการตรึง n=9 มีผลให้บางหน้าตัดเปลี่ยนผลการตรวจหน่วยแรงดัด ผู้ใช้อนุญาตให้เปลี่ยนเมื่อพบผลกระทบเช่นนี้ จึงเปลี่ยนโค้ดหลังตรวจหลักฐานแล้ว การเลือก n=9 ก่อนหน้านี้เป็นสมมติฐานที่ผู้ใช้ตั้งใจ ไม่ใช่ข้อผิดพลาดในการเขียนโค้ดโดยตัวมันเอง

คำว่า “มีนัยสำคัญ” ในรายงานนี้หมายถึง **มีผลเชิงวิศวกรรมต่อผ่าน/ไม่ผ่านขีดจำกัดที่กำหนด** ไม่ใช่การอ้างนัยสำคัญทางสถิติหรือกำหนดเกณฑ์ร้อยละขึ้นมาโดยไม่มีที่มา

## หลักฐานที่ใช้ตัดสิน

คงแรง **active และ passive เต็มค่า** ตาม [กรณีแรงโครงการ](PROJECT_LOAD_CASE_TH.md) รวมถึงวัสดุ ราคา และเกณฑ์อื่นเหมือนกัน แล้วเปรียบเทียบเฉพาะ n สำหรับ f′c=320, fy=4000:

```
Es = 2,040,000 ksc
Ec = 15,100 sqrt(320) = 270,117.0117 ksc
n = Es/Ec = 7.552282573
```

เป็นสมการในเอกสารผู้ใช้ *Reinforced Concrete Design (WSD & SDM)*, Aj. Pongnathee Maneekul, Chapter 10 หน้าเล่ม 342–343 (PDF หน้า 10–11) ดู [ที่มาไฟล์](reference-parameter-baseline/provenance.json) ค่า n=9 สูงกว่าค่าจากสมการนี้ 19.17% แต่การตัดสินไม่ได้อาศัยร้อยละของ n เพียงอย่างเดียว

### ตัวอย่างที่เปลี่ยนผลตรวจดัด

H=5.00, H1=1.20, tt=.20, tb=.25, TBase=.60, B=2.50, toe=.30, heel=1.95 ม.; qa=30 allowable; stem DB28@.10 ม., clear cover=.075 ม. ให้ d=.161 ม. และ Mstem=8.3240 ตันแรง·ม./ม. มิตินี้ผ่านเสถียรภาพทั้งสามตามเกณฑ์โปรเจกต์

| การตรวจ stem | n=9 | n=Es/Ec=7.552283 | ขีดจำกัดที่ใช้ |
| --- | ---: | ---: | ---: |
| fc_actual (ksc) | **142.1757** | **148.4529** | 144 |
| fs_actual (ksc) | 1029.8567 | 1017.4523 | 1700 |
| ผลเฉพาะเกณฑ์หน่วยแรงดัด | ผ่าน | **ไม่ผ่านคอนกรีต** | ตรวจ fc และ fs แยกกัน |

[VB6 จริงยืนยันผลนี้](modular-ratio-sensitivity-native.csv) โดยเรียกตัวตรวจ `CheckSteelOK` กับแรง As และ d เดียวกัน ค่า n=9 ทำให้คำนวณ fc ต่ำกว่าผลของแบบจำลอง Es/Ec จนผลตรวจดัดเปลี่ยน ในตัวอย่างนี้การเพิ่มเหล็กภายในตัวเลือกที่โปรแกรมมีไม่สามารถทำให้รูปทรงนี้ผ่านเกณฑ์ดัดด้วย Es/Ec ได้ตามผลกริด

นี่ไม่ใช่ตัวอย่างของแบบที่รับรองผ่าน WSD ครบ เพราะเกณฑ์ครบยังไม่ยืนยัน คำว่าผ่านในตารางจำกัดเฉพาะการตรวจหน่วยแรงดัด

### ผลในกริดทั้งหมดของกรณีโครงการ

เทียบสถานะจาก VB6 ของมิติเดียวกัน 520,200 แถว โดยทุกแถวใช้แรงทั้งสองฝั่งเหมือนกัน:

- ผ่านเสถียรภาพทั้งสามเท่ากัน: 309,671 ชุด
- ผ่านคัดกรองดัดเมื่อ n=9: 306,427 ชุด
- ผ่านคัดกรองดัดเมื่อใช้ Es/Ec: 305,835 ชุด
- **592 ชุดมิติ** ผ่านคัดกรองดัดเฉพาะเมื่อใช้ n=9; ไม่พบชุดที่เปลี่ยนผลในทิศกลับกันในกริดนี้

ดู [ผลวิเคราะห์พร้อม SHA256 ของหลักฐานต้นทาง](modular-ratio-sensitivity.json) และ [สคริปต์ตรวจ](assess_modular_ratio.py) จำนวน 592 ชุดเป็นชุดมิติในกริดนี้ ไม่ใช่จำนวนทุกชุดเหล็กที่เป็นไปได้ และไม่ได้สรุปว่าผลจะเหมือนกันทุกวัสดุ/ทุกโครงการ

## ผลต่อคำตอบที่ราคาคัดกรองต่ำสุดเดิม

สำหรับ stem ของคำตอบเดิม tb=.40 ม., DB16@.10 ม., d=.317 ม., M=9.7262 ตันแรง·ม./ม.:

| ค่า | n=9 | n=Es/Ec |
| --- | ---: | ---: |
| k_actual จาก As,d จริง | 0.285591 | 0.265304 |
| j_actual จาก As,d จริง | 0.904803 | 0.911565 |
| fc_actual (ksc) | 74.9128 | 80.0430 |
| fs_actual (ksc) | 1686.5534 | 1674.0416 |

fc เพิ่ม 6.85% แต่คำตอบนี้ยังต่ำกว่า 144 และ fs ยังต่ำกว่า 1700 จึงไม่ควรอ้างว่าแบบเดิมล้มเหลวจากการเปลี่ยน n ชุดที่อยู่ห่างขีดจำกัดกับชุดที่อยู่ใกล้ขีดจำกัดให้ผลการตัดสินต่างกันได้

## ค่าที่โปรแกรมใช้ปัจจุบัน

[modWSD.bas](../modWSD.bas) ใช้ `n=2040000/(15100*sqrt(f′c))` โดยเก็บทศนิยมระหว่างคำนวณ [modShared.bas](../modShared.bas) แสดงที่มาว่า n=Es/Ec และยังแยก k_bal,j_bal,R_bal ออกจากค่าที่ตรวจตาม As,d จริง

สำหรับ f′c=320, SD40 ใช้ fc_allow=144, fs_allow=1700:

| n | k_bal | j_bal | R_bal (ksc) |
| ---: | ---: | ---: | ---: |
| **7.552283** | **0.390141** | **0.869953** | **24.437102** |

สูตรยังเป็น k_bal=n·fc_allow/(fs_allow+n·fc_allow), j_bal=1−k_bal/3, R_bal=½fc_allow·k_bal·j_bal การตรวจเหล็กแต่ละคำตอบยังคำนวณ k_actual,j_actual จาก As,d ของคำตอบนั้น ไม่ใช้ R_bal รับรองทุกหน้าตัดแทน

## หลักฐานทดสอบ

[หลักฐาน VB6 ล่าสุด](checks/20260908-214755-492/): คอมไพล์โปรเจกต์หลักและ harness สำเร็จ **267 checks, failures=0; GUI failures=0** รวมกรณีเปลี่ยนผลตรวจดัดข้างต้น การตรวจ H=3,4,5 และพารามิเตอร์หลายกำลังคอนกรีต ตรวจตัวเลขรายงานอิสระ 47 comparisons, mismatches=0

การทดสอบเปรียบเทียบ n ใช้การตั้งค่าเฉพาะภายใน harness แล้วคืนค่าหลังทดสอบ โปรแกรมหลักใช้ Es/Ec ตลอด ไม่ได้สลับ n เพื่อเลือกผลที่ผ่าน

ยังคง active และ passive เต็มค่า, qa ตาม VB6, BA บีบเฉพาะ tb/TBase/Base, ราคาเดิม และสถานะเกณฑ์ WSD ส่วนที่ยังไม่ยืนยัน ไม่รัน batch วิจัย

## ผลคำนวณกรณีโครงการซ้ำหลังเปลี่ยน

[หลักฐาน VB6 รอบปัจจุบัน](full-sizing-checks/20260908-214824-079/): รันกรณีโครงการเดียว passive_factor=1, seed=12345 และงบ BA 5000 evaluations ตามเดิม Input manifest ระบุ modular_ratio_model เป็น Es/Ec และค่าตัวเลข n ที่ใช้ ตรวจกริด 520,200 มิติและตัวเลือกเหล็กของรูปทรงที่เลือก 60 คู่ตรงกับรายการอิสระ ผลสถานะทุกแถวตรงกับหลักฐาน Es/Ec ที่นำมาใช้เปรียบเทียบข้างต้น

คำตอบราคาคัดกรองต่ำสุดยังเป็น tt=.20, tb=.40, TBase=.30, B=2.50, toe=1.00, heel=1.10 ม.; stem DB16@.10, toe/heel DB20@.25 ม. ที่ราคา **8,273.14 บาท/ม.** ผ่านเสถียรภาพสามค่าของโปรเจกต์ 2.1604/1.8097/2.5207 และขีดจำกัดดัดที่ใช้คัดกรอง

กริดปัจจุบันผ่านเสถียรภาพ 309,671 ชุด และผ่านคัดกรองดัด 305,835 ชุด ตัวตรวจ WSD ครบยังไม่รับคำตอบ และ BA ยัง NO_SOLUTION เนื่องจากเกณฑ์ที่เหลือยังไม่ยืนยัน ดังนั้นผลราคายังเป็นราคาคัดกรองเฉพาะกริด ไม่ใช่ราคาที่รับรองการออกแบบครบหรือ global optimum
