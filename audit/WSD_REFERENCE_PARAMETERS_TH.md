# ตรวจ n, k, j, R ตามเอกสารอ้างอิงที่ผู้ใช้ให้

แหล่งหลัก: *Reinforced Concrete Design (WSD & SDM)*, Aj. Pongnathee Maneekul, Chapter 10, ตัวอย่าง 10.1, หน้าเล่ม 342–343 (PDF หน้า 10–11) ในไฟล์ `ออกแบบกำแพงกันดิน อ พงฬ์นธี.pdf` อ่านทั้งข้อความและภาพสูตรแล้ว ไม่แก้ไขไฟล์ต้นฉบับ และไม่อัปโหลดหนังสือทั้งไฟล์เข้า Git เก็บตำแหน่งและ SHA256 ใน [provenance](reference-parameter-baseline/provenance.json)

**พบข้อผิดพลาดในโปรแกรม: ใช้ n=9 คงที่ทุกกำลังคอนกรีต** ทั้งที่เอกสารหา n จาก Es/Ec แล้วเลือกปัดเป็น 9 เฉพาะตัวอย่าง f′c=210 ตัวเลข k, j และ R ในหน้า Parameter ของตัวอย่างนั้นสอดคล้องกับการใช้ n=9 ไม่ควรเหมารวมว่าตารางนี้คำนวณผิดทั้งหมด

## สมการและความหมาย

ใช้หน่วยความเค้นเป็น กก.แรง/ซม.² (ksc):

```
Es = 2,040,000
Ec = 15,100 sqrt(f'c)
n  = Es / Ec
fc_allow = 0.45 f'c
fs_allow = 1,700 สำหรับ SD40 ที่ตัวอย่างเลือกใช้

k_bal = n fc_allow / (fs_allow + n fc_allow)
j_bal = 1 - k_bal / 3
R_bal = 0.5 fc_allow k_bal j_bal
```

n คืออัตราส่วนโมดูลัส ไม่ใช่ค่าคงที่ 9; k_bal คือระยะแกนสะเทินหาร d ของหน้าตัดที่คอนกรีตและเหล็กถึงหน่วยแรงยอมให้พร้อมกัน; j_bal คือแขนโมเมนต์หาร d; R_bal เป็นสัมประสิทธิ์โมเมนต์ของหน้าตัดสมดุลดังกล่าว มีหน่วย ksc ส่วน n, k, j ไม่มีหน่วย ในสูตร k ต้องใช้ **fc_allow** ไม่ใช่ f′c โดยตรง

สมการ k ตรวจซ้ำจากความเข้ากันได้ของความเครียด: εc=fc_allow/Ec, εs=fs_allow/Es และ k=εc/(εc+εs) ส่วน R มาจากแรงอัดรูปสามเหลี่ยม C=fc_allow·b·k·d/2 คูณแขน j·d จึงต้องมีตัวคูณ 1/2

| f′c=210 ใช้ Es/Ec ไม่ปัดระหว่างทาง | 9.322740 | 0.341340 | 0.886220 | 14.293246 |

Ec ของ f′c=210 คือ 218,819.7889 ksc ตรงกับ 218,820 ที่พิมพ์ในเอกสาร; Ec ของ f′c=320 คือ 270,117.0117 ksc จึงนำ n=9 จากตัวอย่างเดิมมาใช้ค้างไม่ได้ โค้ดใหม่เก็บทศนิยมจนจบและปัดเฉพาะการแสดงผล เอกสารตัวอย่างบอกว่าเลือก n=9 แต่หน้าที่ตรวจไม่ได้ให้กฎทั่วไปว่าต้องปัดลงหรือปัดเป็นจำนวนเต็มใกล้ที่สุด จึงไม่สร้างกฎปัดขึ้นเอง

ถ้านำเฉพาะ k=.333 และ j=.889 ที่พิมพ์แบบปัดแล้วมาคูณ จะได้ R=13.987748 ไม่เท่ากับ 14.00 พอดี แต่เมื่อใช้ k,j ก่อนปัดได้ R=14.004803 ซึ่งแสดงเป็น 14.00 ได้ ความต่างนี้มาจากลำดับการปัด ไม่ใช่เหตุผลเพียงพอให้ตัดสินว่าสูตร R ผิด

## ค่าหน้าตัดสมดุลกับเหล็กที่เลือกจริงต้องแยกกัน

เมื่อเลือก DB และระยะเรียงแล้ว ต้องใช้ As จริงและ d จริงหาแกนสะเทินจากสมดุลหน้าตัดแตกร้าว:

```
rho = As / (b d)
k_actual = sqrt((n rho)^2 + 2 n rho) - n rho
j_actual = 1 - k_actual/3
fs_actual = abs(M) / (As j_actual d)
fc_actual = 2 abs(M) / (b k_actual j_actual d^2)
```

ตัวอย่างเดิมที่เลือก stem หนาโคน .40 ม., clear cover .075 ม., DB16@.10 ม. มี d=.317 ม. และ As=20.106193 ซม.²/ม. เมื่อใช้ n ใหม่จะได้ **k_actual=.265304, j_actual=.911565** ซึ่งต่างจาก k_bal=.390141, j_bal=.869953 อย่างชัดเจน

สำหรับ M=9.7262 ตันแรง·ม./ม. ของหน้าตัดนี้ fc_actual=80.0430 และ fs_actual=1,674.0416 ksc ส่วนโมเมนต์ยอมให้ตามขีดจำกัดดัดที่ใช้ในแบบจำลองคือ min(Mc,Ms)=**9.877019 ตันแรง·ม./ม.** ไม่ใช่นำ R_bal·b·d² มารับรองเหล็กคู่นี้โดยตรง ค่า R_bal ใช้กับสภาวะสมดุลซึ่งต้องมีปริมาณเหล็กสอดคล้องกัน

เมื่อ R เป็น ksc, b และ d เป็นเซนติเมตร: M=Rbd² มีหน่วย กก.แรง·ซม. หาร 100,000 เป็นตันแรง·ม.; ถ้า b,d เป็นเมตร M=10Rbd² ตันแรง·ม. ฟังก์ชัน `CalculateMomentCapacity` เดิมแปลงหน่วยถูกแล้วและคงไว้

## ข้อคลาดเคลื่อนอื่นที่เห็นขณะอ่านหน้าตัวอย่าง

- หน้าเล่ม 343: สูตรเขียน M=PaH3/3 แต่บรรทัดแทนค่าเขียน 13.284×6/2 ซึ่งต้องได้ 39.852 ไม่ใช่ผล 26.568 ที่พิมพ์ไว้ ผล 26.568 ตรงกับ **หาร 3** ตามแรงสามเหลี่ยม จึงเป็นการแทนค่าที่พิมพ์ผิด ไม่เปลี่ยนแขนแรงในโปรแกรมเป็น H/2
- หน้า 342: บรรทัด fs เขียน 0.5×4000=2000 แล้วแสดง 1700 ต้องแยกค่าคำนวณ 2000 ออกจากค่าที่ตัวอย่างนำไปใช้ 1700 ไม่อ่านว่า 2000 เท่ากับ 1700 โค้ดคงค่า SD40 ที่ตัวอย่างใช้อยู่ ไม่เปลี่ยนเป็น 2000 โดยอนุมานเอง
- หน้า 350–351 (PDF หน้า 18–19): FBD ของ heel ใช้ V=24,486 กก.แรง แต่ตรวจ shear ในหน้าถัดไปใช้ 14,245 โดยไม่แสดงที่มาของการลดแรง ถ้าใช้ V ที่หน้ารองรับตาม FBD เดิมและ d=47.5 ซม. จะได้ v=5.15495 ksc ซึ่งเกิน 0.29√210=4.20250 ที่เอกสารใช้ จึงยังตามไปสรุป OK จาก v=3.00 ไม่ได้จนกว่าจะอธิบายแรงและหน้าตัดที่ตรวจให้สอดคล้องกัน
- ค่า d=55−7.5=47.5 ซม. ในตัวอย่างไม่ได้หักรัศมีเหล็ก หาก 7.5 หมายถึง clear cover จะต้องหัก DB/2 เพิ่ม โปรเจกต์นี้ใช้ความหมาย clear cover ตามคำสั่งผู้ใช้และ d ตามเหล็กจริงต่อไป

รายการนี้เป็นข้อสังเกตจากหน้าที่อ่านประกอบการตรวจพารามิเตอร์ ไม่ใช่การรับรองว่าตรวจตัวอย่างทั้งบทครบทุกบรรทัด และไม่ได้คัดลอกค่าที่มีข้อขัดแย้งเหล่านี้เข้าตัวตรวจ
