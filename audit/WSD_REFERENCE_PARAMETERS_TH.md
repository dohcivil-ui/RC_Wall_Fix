# ใช้ n=9 ตามสมมติฐานที่ผู้ใช้เลือก

**ผู้ใช้ชี้แจงว่าตั้งใจเลือก n=9 สำหรับงานนี้ตั้งแต่ต้น** การเรียกค่านี้ว่าเป็นข้อผิดพลาดในโปรแกรม และเปลี่ยนเป็น Es/Ec อัตโนมัติใน commit f2ed23a เป็นการตีความเจตนาผู้ใช้ผิดของผู้ช่วย จึงคืนค่า **n=9** แล้ว ไม่ถือว่าการเลือกค่านี้เองเป็นบั๊กของซอฟต์แวร์

ที่มาที่ผู้ใช้ใช้ประกอบการเลือก: *Reinforced Concrete Design (WSD & SDM)*, Aj. Pongnathee Maneekul, Chapter 10, ตัวอย่าง 10.1 หน้าเล่ม 342–343 (PDF หน้า 10–11) ในไฟล์ `ออกแบบกำแพงกันดิน อ พงฬ์นธี.pdf` ดู [ตำแหน่งและ SHA256 ต้นฉบับ](reference-parameter-baseline/provenance.json) ไม่ได้แก้หรืออัปโหลดหนังสือทั้งไฟล์

## สมมติฐานและสมการที่ใช้งานจริง

โปรแกรมใช้ `PROJECT_MODULAR_RATIO=9` กับทุกกำลังคอนกรีตในโปรเจกต์ตามการเลือกของผู้ใช้ แล้วคำนวณพารามิเตอร์ใหม่จากหน่วยแรงยอมให้ของวัสดุ:

```
n = 9  (user-selected project assumption)
fc_allow = 0.45 f'c
fs_allow = 1,700 สำหรับ SD40 ที่ใช้ในกรณีนี้
k_bal = n fc_allow / (fs_allow + n fc_allow)
j_bal = 1 - k_bal/3
R_bal = 0.5 fc_allow k_bal j_bal
```

n, k, j ไม่มีหน่วย ส่วน R มีหน่วย กก.แรง/ซม.² (ksc) สูตร k ใช้ **fc_allow** ไม่ใช่ f′c โดยตรง โค้ดไม่ได้ตรึง k,j,R ตามตัวอย่าง f′c=210 เพราะค่าเหล่านี้ยังเปลี่ยนตาม fc_allow และ fs_allow

| กรณีใช้ n=9 | k_bal | j_bal | R_bal (ksc) |
| --- | ---: | ---: | ---: |
| f′c=210, SD40 ตามตัวอย่าง | 0.333464 | 0.888845 | 14.004803 |
| **f′c=320, SD40 ของงานนี้** | **0.432577** | **0.855808** | **26.654584** |

ค่า k≈.333, j≈.889, R≈14 ในตัวอย่างอ้างอิงสอดคล้องกันเมื่อเลือก n=9 ความต่างเล็กน้อยเมื่อคูณตัวเลขที่แสดงเพียงสามตำแหน่งเป็นผลจากการปัด ไม่ใช่หลักฐานว่าสูตร R ผิด

ความหมายทั่วไปยังคงเป็น n=Es/Ec แต่ **ค่า n ที่เลือกใช้ในแบบจำลองงานนี้คือ 9** หากคำนวณด้วยสมการ Ec=15100√f′c และ Es=2040000 จะได้ n=9.32274 ที่ f′c=210 และ n=7.55228 ที่ f′c=320 ค่านี้เก็บไว้เป็นการเปรียบเทียบ ไม่ใช่ค่าที่โปรแกรมนำมาแทนการเลือกของผู้ใช้ และไม่ได้กล่าวว่า Es/Ec จากสมการดังกล่าวเท่ากับ 9 ทุกกรณี

## ตรวจเหล็กจริงด้วย k,j ของหน้าตัดจริง

ค่า k_bal,j_bal,R_bal เป็นพารามิเตอร์ของหน้าตัดสมดุลที่คอนกรีตและเหล็กถึงหน่วยแรงยอมให้พร้อมกัน การตรวจ DB และระยะเรียงที่เลือกยังต้องหาแกนสะเทินจาก As กับ d จริง:

```
rho = As/(b d)
k_actual = sqrt((n rho)^2 + 2 n rho) - n rho
j_actual = 1 - k_actual/3
fs_actual = abs(M)/(As j_actual d)
fc_actual = 2 abs(M)/(b k_actual j_actual d^2)
```

กรณี stem หนาโคน .40 ม., clear cover .075 ม., DB16@.10 ม. มี d=.317 ม. และ As=20.106193 ซม.²/ม. ใช้ n=9 ได้ **k_actual=.285591 และ j_actual=.904803** ไม่ใช้ k_bal=.432577 หรือ j_bal=.855808 แทนการตรวจหน้าตัดนี้

ที่ M=9.7262 ตันแรง·ม./ม. ได้ fc_actual=74.9128 และ fs_actual=1686.5534 ksc ซึ่งต่ำกว่าขีดจำกัดดัด 144 และ 1700 ที่ใช้ตามลำดับ โมเมนต์ยอมให้ตามขีดจำกัดดัดและเหล็กคู่นี้คือ **min(Mc,Ms)=9.803745 ตันแรง·ม./ม.** ไม่ใช่รับรองด้วย R_bal·b·d² เพียงอย่างเดียว

## ผลมิติ เหล็ก และราคา

กรณีหลัก H=5, H1=1.20 ม., f′c=320, fy=4000, qa=30 allowable ตาม VB6 ใช้ passive เต็มค่า: tt=.20, tb=.40, TBase=.30, B=2.50, toe=1.00, heel=1.10 ม.; **stem DB16@.10, toe และ heel DB20@.25 ม.**

เสถียรภาพพลิกคว่ำ/เลื่อน/qa ต่อ qmax ยังเท่ากับ 2.1604/1.8097/2.5207 ผ่านเกณฑ์โปรเจกต์เฉพาะสามรายการนี้ ราคาคัดกรองต่ำสุดของกริดยังเป็น **8,273.14 บาท/ม.** ไม่ใช้ passive ได้ 9,144.08 บาท/ม. คงสูตรราคาเดิม ไม่ได้ปรับเพื่อรักษาค่าราคา

กรณี passive เต็มค่าผ่านเสถียรภาพ 309,671 ชุดและผ่านคัดกรองดัด 306,427 ชุด; ไม่ใช้ passive ผ่าน 292,021 และ 288,781 ชุดตามลำดับ ดู [รายการหน่วยแรงและราคาล่าสุด](recalculation-details.json)

การยืนยัน n=9 เป็นสมมติฐานของงานไม่ได้เปิด `WSDReviewed` หรือเปลี่ยนสถานะเกณฑ์อื่นที่ยังตรวจไม่ครบ ตัวตรวจจริงและ BA จึงยัง NO_SOLUTION ราคาข้างต้นเป็นผลคัดกรองเฉพาะกริดและเกณฑ์ดัดที่ระบุ ไม่ใช่ global optimum ของแบบที่ผ่านครบ ยังไม่ได้รัน batch วิจัย 30 trials และยังคง BA บีบเพียง tb/TBase/Base

## ข้อคลาดเคลื่อนในตัวอย่างที่แยกจากการเลือก n

- หน้า 343: สูตร M=PaH3/3 แต่แทนค่าพิมพ์ 13.284×6/2 ขณะที่ผล 26.568 ตรงกับหาร 3 ตามแรงสามเหลี่ยม
- หน้า 342: ค่า 0.5×4000=2000 ต้องแยกจาก fs=1700 ที่ตัวอย่างเลือกนำไปใช้ ไม่อ่านว่า 2000 เท่ากับ 1700
- หน้า 350–351: FBD ของ heel ให้ V=24,486 กก.แรง แต่ตรวจ shear ด้วย 14,245 โดยไม่อธิบายที่มาของการลดแรง ถ้าใช้แรงที่หน้ารองรับตาม FBD และ d=47.5 ซม. จะได้ v=5.15495 ksc เกิน 4.20250 ที่ตัวอย่างใช้ จึงต้องตรวจให้แรงและหน้าตัดที่พิจารณาสอดคล้องกันก่อนตามข้อสรุป OK
- d=55−7.5 ซม. ในตัวอย่างต้องระวังความหมาย cover สำหรับงานนี้ใช้ clear cover และหัก DB/2 ตามเหล็กจริงต่อไป
