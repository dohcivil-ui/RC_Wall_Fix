# ผลตรวจ H = 5 เมตร จาก VB6 จริง

วันที่ 8 กันยายน 2569 — รายงานนี้แยกการปฏิเสธหน้าตัดออกจากการยืนยันมาตรฐาน ไม่ใช้ค่าทดสอบสมมติเป็นเกณฑ์ออกแบบ

**ผลที่ทราบแล้ว:** stem หนา 0.20 ม. ใช้ DB12@0.25 ไม่เพียงพอในแบบจำลองดัดที่ตรวจ แม้หัก passive เต็มค่า ส่วนแบบที่ BA เคยพบยังไม่ใช่แบบที่ยืนยันว่าผ่าน วสท. 2562

## 1. กรณีอ้างอิง DB12@0.25

ข้อมูล: H = 5.00 ม., TBase = 0.30 ม., H1 = 1.20 ม., γดิน = 1.8 ตันแรง/ม.³, φ = 30°, stem หนา 0.20 ม., clear cover = 0.075 ม., f′c = 320 และ fy = 4000 กก.แรง/ซม.²

ขอบเขตสุดท้ายมาจากสมดุล **M = Tz**, ให้ **T ≤ As·fy** และ **z ≤ d** จึงได้ **M ≤ As·fy·d** สำหรับแบบจำลองดัดล้วน เหล็กรับแรงดึงชั้นเดียวที่ใช้อยู่ ค่านี้เป็นเพียงเงื่อนไขจำเป็น ไม่ใช่กำลังอนุญาต WSD และไม่ต้องสมมติ n หรือค่าสัมประสิทธิ์มาตรฐานเพื่อใช้ปฏิเสธกรณีนี้ การไม่เกินขอบเขตนี้เพียงอย่างเดียวไม่ทำให้แบบผ่าน

เมื่อใช้แบบจำลองหน้าตัดแตกร้าวเดิม n = 9 กรณี active ให้ fc = 691.5640 และ fs = 20,883.9863 กก.แรง/ซม.² เทียบขีดจำกัดเดิม 144 และ 1700 ตามลำดับ ค่าหน่วยแรงนี้เป็นผลของแบบจำลองเชิงเส้น ไม่ใช่การทำนายพฤติกรรมหลังเหล็กคราก และขีดจำกัดเดิมยังไม่ได้ยืนยันจากข้อกำหนด วสท. ฉบับจริง

ไม่ตัดสิน toe/heel หรือเสถียรภาพทั้งกำแพงให้กรณีอ้างอิงนี้ เพราะผู้ใช้ระบุเฉพาะหน้าตัดและเหล็ก stem มิติฐานที่ใช้ประกอบ fixture ไม่ถือเป็นแบบที่ผู้ใช้อนุมัติ

## 2. ตรวจแบบที่ BA เคยพบอีกครั้ง โดยปิดเกณฑ์สมมติ

นี่คือคำตอบจาก **การทดสอบ GUI ก่อนหน้า ซึ่งใช้เกณฑ์สมมติเพื่อทดสอบซอฟต์แวร์** นำมาตรวจใหม่ด้วย WSDReviewed=False และไม่ตั้งค่าแรงเฉือน/เหล็กขั้นต่ำ ไม่ใช่คำตอบที่การค้นหาในโหมดใช้งานจริงรับรองแล้ว และไม่ใช่ข้อเสนอเหล็กสำหรับก่อสร้าง

**ผลรวม: INDETERMINATE_WSD — ยังสรุปผ่านมาตรฐานไม่ได้** เหตุผลที่ยังขาดคือข้อกำหนดและเงื่อนไขใช้ n/หน่วยแรงอนุญาต, นิยามแรงเฉือนและหน้าตัดวิกฤต, เหล็กขั้นต่ำแยกองค์อาคาร, ระยะเรียง/เหล็กกระจาย/ระยะฝังยึด และรายละเอียด cover กับลำดับชั้นเหล็ก ไม่ใช่เหตุผลว่าโปรแกรมยังไม่ได้คอมไพล์

ค่า d ที่รายงานสมมติให้เหล็กหลักอยู่ชั้นนอกสุด หากมีเหล็กขวางคั่นระหว่างผิวคอนกรีตกับเหล็กหลัก ต้องหักขนาดเหล็กขวางเพิ่มเติม การตรวจฉบับนี้ยังไม่ครอบคลุมรายละเอียดนั้น

- [Native regression](native-regression.txt): **140 checks, failures=0** รวมสูตรอิสระ H = 3, 4, 5 ม., หน้าตัดไม่ผ่าน, การนับ evaluation และรายงานใหม่
- [GUI regression](gui-regression.txt): **GUI failures=0** จากการโหลดฟอร์มและเรียกปุ่มจริง กรณีเกณฑ์สมมติในไฟล์นี้มีไว้ทดสอบโปรแกรมเท่านั้น
- [คำนวณอิสระเทียบรายงาน H5](report-independent-checks.txt): **44 ค่า, mismatches=0** ที่ความละเอียดรายงาน 4 ตำแหน่ง การตรวจ Python นี้ใช้ตรวจเลข ไม่ใช้แทนหลักฐานรัน VB6
- [หลักฐานรอบสุดท้าย](checks/20260908-194807-354/): compile logs ของทั้งสาม EXE, native/GUI logs, รายงาน และ SHA256 ของ EXE กับ source ของรายงาน
- [แหล่งมาตรฐานที่ตรวจค้น](WSD_PRIMARY_SOURCE_SEARCH.md): [บัญชีหนังสือของ วสท.](https://eit.or.th/showcase/EIT/issue4_68/files/basic-html/page90.html) ยืนยันรหัส 011007-19 และ ISBN แต่ไม่ได้เผยข้อกำหนดตัวเลขที่ยังขาด จึงไม่ใช้การมีชื่อหนังสือเป็นหลักฐานว่าครบตามมาตรฐาน

รันซ้ำได้ด้วย `powershell -NoProfile -ExecutionPolicy Bypass -File audit\run_checks.ps1` จากโฟลเดอร์โปรเจกต์ โดยเครื่องต้องมี VB6 compiler ตาม path ในสคริปต์ EXE ที่คอมไพล์ล่าสุดอยู่ที่ `audit\RC_RT_HCA_v2.exe` และไม่ได้เก็บ binary ใน Git

แก้โค้ดใช้งานจริงเฉพาะ `modShared.bas` เพื่อเพิ่มรายงานและระบุผลให้ชัด ใช้ตัวคำนวณเดียวกับ validator ไม่เปลี่ยนกลไก BA: ยังบีบเฉพาะ tb, TBase, Base ไม่แก้ราคา และไม่เปิด WSDReviewed ในโปรแกรมจริง

**ยังไม่ได้ทำ:** batch วิจัย, การรับรองข้อกำหนด วสท. ครบถ้วน และแบบรายละเอียดก่อสร้าง ผลทดสอบซอฟต์แวร์ไม่ใช่การรับรองความปลอดภัยของแบบ
