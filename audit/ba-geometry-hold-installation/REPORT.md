# ติดตั้ง BA รุ่นที่ผ่านการทดสอบเข้าโปรเจกต์หลัก

ผู้ใช้อนุญาตให้แก้โค้ดหลักเมื่อผล H=5 ม., f′c=320 จำนวน20ครั้งต่อวิธียังได้เปรียบในภาพรวม จึงติดตั้งหลังตรวจผลและ source ครบ โดยใช้ candidate เดิมที่ทดสอบ H3/H4/H5 ทุก byte ไม่มีการปรับอัลกอริทึมระหว่างการติดตั้ง

## หลักฐานที่ใช้ตัดสิน

| ผล H5/fc320 | BA | HCA เดิม |
|---|---:|---:|
| ถึงราคาอ้างอิง 8,538.418920 บาท/ม. | 11/20 | 4/20 |
| รอบเฉลี่ยถึงราคาอ้างอิงหรือใช้ครบงบทุกครั้ง | 2,719.85 | 4,346.30 |
| SD รอบแบบรวมทุกครั้ง | 2,141.78 | 1,379.23 |
| ราคาสุดท้ายเฉลี่ย บาท/ม. | 8,564.42 | 8,617.09 |
| SD ราคาสุดท้าย | 40.24 | 115.62 |

BA ใช้จำนวนรอบเฉลี่ยแบบรวมทุกครั้งน้อยกว่า37.42% และถึงราคาอ้างอิงมากกว่า ครั้งที่ไม่ถึงใช้จำนวนงบจริง5,000ในการสรุป ไม่ถือว่าถึงเป้าที่5,000 การติดตั้งอิงความได้เปรียบโดยรวมตามเกณฑ์ผู้ใช้ประมาณ10% ไม่ได้บังคับ20/20หรือชนะทุกtrial

SD รอบรวมของ BA **สูงกว่า** HCA ในชุดนี้ ต้องเก็บไว้ตามจริง ขณะที่ SD ราคาสุดท้ายและ SD รอบเฉพาะครั้งสำเร็จของ BA ต่ำกว่า (456.18 เทียบ807.70) จำนวนครั้งที่ไม่ถึงของทั้งสองวิธีต่างกันมาก จึงไม่ใช้ SD ค่าเดียวแทนภาพรวม ผลไม่ได้รับประกันความเหนือกว่าทุกกรณีและไม่ใช่การทดสอบนัยสำคัญ

## ไฟล์หลักที่แก้

- modBA.bas: แทน control ที่เคยเรียก HCA ด้วย candidate geometry-hold ที่ทดสอบจริงตรงทุก byte คงจุดกึ่งกลางร่วม tb/TBase/Base, การรับคำตอบเมื่อผ่านทุกเงื่อนไขและดีขึ้น, การคืนสถานะเมื่อปฏิเสธ และทำงานเต็มจำนวนรอบ มิติทั้งห้าสุ่มอิสระแบบคงเดิม2/3 ขยับ±1อย่างละ1/6 พร้อมคู่เหล็กทั้งสามแบบ half-stay ตามรุ่นที่ทดสอบ
- Form1.frm: เปลี่ยนเฉพาะข้อความ BA (HCA baseline) เป็น BA และ BA HCA baseline - Trial เป็น BA - Trial
- HANDOFF.md: บันทึกสถานะที่ติดตั้งแล้วและผลทดสอบ

HCA, modShared, สูตร หน่วย ราคา ขอบเขต ชุดตรวจ UI ส่วนอื่น การส่งออกCSV และไฟล์VBPเดิมไม่เปลี่ยน เก็บรูปแบบbyte/CRLF/noBOMเดิม สำรองสองsourceก่อนแก้ไว้ในโฟลเดอร์ before
